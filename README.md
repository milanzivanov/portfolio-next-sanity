# Milan Živanov | Portfolio & CMS

A high-performance portfolio engineered to bridge the gap between creative design and robust web development. This project serves as a live demonstration of modern frontend architecture, utilizing a decoupled approach for maximum speed and scalability.

## 🚀 Tech Stack

- **Frontend:** [Next.js](https://nextjs.org/) (App Router, Server Components)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) (Responsive & Mobile-first design)
- **Backend/CMS:** [Sanity.io](https://www.sanity.io/) (Headless CMS for dynamic content)
- **Deployment:** [Vercel](https://vercel.com/)
- **Optimization:** AI-assisted development workflow for clean code and performance.

## ✨ Key Features

- **Engineering-First Approach:** Focused on technical precision, process optimization, and clean component architecture.
- **Headless CMS Integration:** Full integration with Sanity CMS, allowing for real-time content management without redeploying.
- **Performance Optimized:** Leveraging Next.js Image Optimization and Geist font family for near-instant load times.
- **Responsive UI:** Fully fluid and accessible layouts designed in Figma and transformed into efficient code.
